# CLAUDE.md

## Project Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Git

## Project Rules

### Forms

- Every form field must have an associated `<label>`.
- Validate all user input before form submission.
- Display validation messages directly below the corresponding input.
- Prevent form submission when validation fails.

### Accessibility

- Use `aria-invalid` for invalid form fields.
- Support keyboard navigation for all interactive elements.
- Provide visible focus styles for buttons and inputs.

### JavaScript

- Organize code into reusable functions.
- Avoid unnecessary global variables.
- Use `addEventListener()` instead of inline event handlers.
- Separate validation logic from UI update logic.

### UI

- Keep the layout responsive for desktop and mobile.
- Use consistent spacing and typography.
- Show a success message after saving settings.
- Disable the submit button while processing.

### Git

- Use Conventional Commits for every commit.
- Keep commits focused on a single change.
